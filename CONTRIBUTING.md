# Contributing Guide

Thanks for your interest in contributing! This guide walks through how to submit changes to this repository.

## How to Contribute

1. **Report bugs and request features** by opening an issue with a clear title and description.
2. **Create a feature branch** for any change you want to make (e.g., `drill-add-contributing`).
3. **Make your changes** and make sure they're well-tested and documented.
4. **Open a pull request** into the default branch (`main`) and link the related issue in the description.
5. **Request a review** from a maintainer and respond to feedback politely.
6. **Close out the issue** as completed once the pull request has been merged.

## Pull Request Tips

- Keep pull requests small and focused on a single purpose.
- Include a pull request description that references the issue number (e.g., "Closes #6").
- Add a comment on the issue pointing readers to the pull request so the trail stays visible.

## Code Style

- Follow the existing style in the repository.
- Add or update tests when behavior changes.
- Comment your code where intent isn't obvious.

## Getting Help

If you're stuck, leave a comment on the issue or open a discussion, and a maintainer will weigh in.
