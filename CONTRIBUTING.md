# Contributing Guide

This guide walks new contributors through the basics of contributing to this repository.

## How to contribute

- **Open an issue first.** Describe what you want to change and why before writing any code.
- **Create a feature branch** off `main` with a short, descriptive name (for example `demo-add-contributing-guide`).
- **Make small, focused changes** and commit them with clear messages.
- **Submit a pull request** into `main`, referencing the issue number in the description.
- **Request a review** from a maintainer and leave a comment on the issue pointing readers to the pull request.
- **Respond to feedback** and push follow-up commits to the same branch until the review is resolved.
- **Maintainers close merged issues as completed** to keep the board tidy.

## Tips

- Keep pull requests small so reviews are fast and mistakes easy to undo.
- Reference the issue in your PR description (e.g. "Closes #8") so it auto-closes when merged.
- If you are unsure about anything, ask in the issue — open conversations are welcome.
